# Christeena & Samuel — digital invitation

One static invitation page, the same for every guest. Live at https://joyaljohnson.github.io/christeena/

## Rules
- **This project stands alone.** Never look at, reuse or copy anything from other wedding projects (including Akeena's).
- **No logins, PINs, personal notes, database or admin.** Keep it a single static page.
- **Build, commit or push only when the user says so.** After every push, confirm the GitHub Actions run succeeded and that the live page loads. Don't assume it worked.
- **All wording lives in `content.json`.** That includes names, events, times, venues, Maps links, sections and their order. Don't hard-code content in `build.mjs`, `src/` or HTML.
- **Mobile-first at 360 / 390 / 430px wide.**
  - No horizontal scroll.
  - Tap targets at least 44px.
  - WCAG AA contrast: text uses `--ink` or `--gold-text`; `--gold` and the foil gradient are for decoration only.
  - Respect `prefers-reduced-motion`: the envelope becomes a fade, and shimmer, bob and reveal effects switch off.
- **Visual style:** ivory paper, gold line-art florals, gold wax seal, Pinyon Script for names and titles, Cormorant Garamond for text. Fonts are self-hosted in `assets/fonts/`; don't add external requests.
- **Artwork:**
  - Source files live in `artwork/` and are never edited.
  - Run `python tools/process_art.py` (needs Pillow) to regenerate `assets/`.
  - Line art is black on white and gets painted gold through a CSS mask.
  - When replacing a file, keep its exact filename.
  - Any art not yet supplied gets a placeholder of the right size with the exact final filename.
- **The site stays hidden from search engines** (`noindex` meta).
- **Every event gets both buttons:** "Get directions" (Maps link) and "Add to calendar" (a static `.ics` file in `dist/ics/`, generated by the build in UTC from the IST times).
- **WhatsApp preview** is `assets/og-image.jpg` at 1200×630. Regenerate it with `tools/make-og.sh` after changing the envelope.

## Commands
- Build: `node build.mjs` (no dependencies). Output goes to `dist/`, which isn't committed; CI builds it.
- Preview: `.claude/launch.json` builds, then serves `dist/` on http://localhost:4173
- Deploy: push to `main` and `.github/workflows/deploy.yml` publishes to Pages. In the repo settings, Pages → Source must be "GitHub Actions".

## Files
- `content.json` — all content
- `build.mjs` — page and `.ics` generator
- `src/style.css`, `src/main.js` — styles, envelope animation, ribbon physics, music, countdown
- `assets/` — web-ready art, fonts, music
- `artwork/` — original art
- `tools/` — art processing and OG image scripts
